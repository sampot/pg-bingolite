# pg-bingolite

復古**賓果閃燈機**瀏覽器小品（機台感燈板）：押娛樂幣開局 → 跑燈開號 → 卡上點亮 → 連線結算。純娛樂、無真實金錢／兌現。

- **玩法：** 5×5 賓果卡（中心免費格）；每局 10 幣自動開 20 號，開號帶跑燈動畫；橫／直／斜連線給娛樂獎金，全盤另有倍率
- **音效：** Web Audio 即時合成（投幣／跑燈／中卡／連線），無商業機台取樣
- **機台感：** 開號顯示器流水燈、加速跑燈、中獎彩光

也可當作 [Playgrounds（遊樂場）](https://play.samkuo.me/) 的 **SAM**（`index.html` 入口）。

```bash
npx --yes serve .
# 或
python3 -m http.server 8080
```

瀏覽器需允許音訊（點一下頁面後音效才會出聲）。

## 操作

| 操作 | 說明 |
| --- | --- |
| **+50 幣** | 增加娛樂幣 |
| **開始一局** | 扣 10 幣，跑燈開 20 號並標記卡面 |
| **新卡** | 產生新的 5×5 賓果卡 |
| **清除本局** | 清空標記與已開號（保留同一張卡） |
| **音效開／關** | 靜音切換 |

連線娛樂賠率（相對一局 10 幣）：1 線 ×2、2 線 ×5、3 線 ×12、4 線 ×25、5 線 ×40、全盤 ×80。版面與賠率為本專案原創，僅向「賓果閃燈／燈板開號」機台類型致敬，不還原任何特定機台。
